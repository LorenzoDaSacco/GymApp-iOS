# GymApp iOS aggiornata

Progetto SwiftUI nativo per iPhone, basato sulla versione aggiornata `app(3).py`.

- Schede UPPER / LOWER / FULLBODY
- Esercizi della scheda personale
- Serie, ripetizioni, peso e completamento
- Riconoscimento automatico del gruppo muscolare
- Mappa muscolare
- Tema chiaro/scuro
- Salvataggio locale sull'iPhone

Richiede Xcode su macOS per la compilazione/signing.
